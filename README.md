## Descripción

Este repositorio contiene el expediente de auditoría interna desarrollado sobre el escenario académico de Comercializadora Norte.

Se documentan mecanismos de auditoría de PostgreSQL y MongoDB, calidad de datos, responsabilidades, conservación, políticas de seguridad, conciliación de cambios y hallazgos técnicos.

## Consideraciones de seguridad

Las bitácoras E5 y E6 incluidas en esta entrega corresponden a copias redactadas.

Los archivos originales se conservan fuera de este repositorio, junto con sus hashes de integridad.

Se incluyen manifiestos SHA-256 para verificar las versiones compartidas.

La revisión automatizada reduce riesgos de exposición, pero no sustituye una revisión manual final antes de publicar.
